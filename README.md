# 🍽️ My Restaurant Website

Welcome to **My Restaurant** — a fully responsive, visually appealing restaurant website built as a personal project to showcase my frontend development skills.

This project is part of my **personal portfolio** and reflects my ability to design and build interactive, real-world interfaces using **HTML, CSS, and JavaScript**.

---

## 🚀 Features

- **Responsive Homepage**  
  Includes a welcoming hero section and customer testimonials to highlight positive dining experiences.

- **Interactive Menu**  
  A categorized gallery showcasing starters, main courses, and desserts, with appealing visuals and pricing.

- **Reservation System**  
  - Selectable seating areas: *Window* and *Patio*  
  - Table availability and capacity displayed  
  - Interactive selection with form validation and dynamic reservation confirmation

- **Contact Page**  
  A simple contact form, business details, and an embedded map.

---

## 🛠️ Technologies Used

- **HTML5** – semantic structure  
- **CSS3** – layout, animations, and responsiveness  
- **JavaScript (Vanilla)** – table selection logic and DOM manipulation  
- **Font Awesome** – icons  
- **Google Fonts** – Montserrat and Open Sans

---
